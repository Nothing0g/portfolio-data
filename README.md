# Shubham Kumar — AI Resume Context Bundle

This bundle is designed to be fed into another AI for resume tailoring, candidate-role matching, application drafting, and interview preparation.

## Start here
1. `01_Profile/MASTER_PROFESSIONAL_PROFILE.md` — complete human-readable candidate context, career history, project bank, skill inventory, resume preferences, company/role map, and verification notes.
2. `01_Profile/CANDIDATE_PROFILE.json` — structured version for ingestion into an AI system or database.
3. `02_LaTeX_Source/RESUME_SOURCE_INDEX.md` — index of actual LaTeX sources and company/role versions.
4. `02_LaTeX_Source/` — original LaTeX files copied as-is, including the generic base and template.
5. `03_Resume_PDFs/` — selected saved resume outputs/reference versions.
6. `04_Company_JDs_and_Role_Material/` — JDs, campus role materials, case brief, and interview/prep reference documents found in the saved library.

## Scope and exclusions
- Career-tracker and cold-email Excel workbooks were explicitly excluded at the candidate's instruction.
- The package includes only professional/resume-related information.
- Some role materials are saved PDFs or Markdown rather than `.tex` files. The index distinguishes those clearly.
- A `.tex` or PDF resume proves a draft exists; it does not prove the application was submitted or the candidate was shortlisted/offered a role.
- Original `.tex` sources are not rewritten, normalised, or redesigned in this bundle.

## Key caution
Read the verification checklist in the master profile before using disputed CGPA, school marks, CultFit numbers/status, team size, certificates, or project metrics. Do not claim synthetic prototypes are production deployments or that public project data came from NTPC/real company systems.
